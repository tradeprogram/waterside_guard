# 배포 — Vercel(UI) + 최소 백엔드

## 구조

```
브라우저
 ├─ 조회 (지도·목록·근거·검증·보고서 데이터)  →  Vercel 정적 파일 (ui/public/api/**.json)
 └─ 대화·등록 (AGENT·주간의견·점검결과)        →  최소 백엔드 (api_min.py)
```

조회용 응답은 전부 사전계산 결과라 요청마다 계산할 이유가 없다. 정적 파일로 내리면
콜드스타트나 함수 타임아웃으로 화면이 비는 사고가 원천 차단된다 — 심사 중 링크를 여는
순간이 하필 그때일 수 있으므로 이게 가장 큰 이유다.

실시간 계산이 남는 건 셋뿐이다.

| 엔드포인트 | 왜 정적화가 안 되나 |
|---|---|
| `POST /sites/{id}/ask` | Gemini 호출. 실측 30~40초 |
| `POST /reports/weekly` | 같음 |
| `POST /inspections` | 상태 변경(인메모리) |

## 1. 정적 스냅샷 굽기

```bash
python -m uvicorn api_server:app --port 8001   # 전체 API를 로컬에 띄운다
python scripts/build_static_api.py             # -> ui/public/api/
```

GEE 썸네일까지 실제 이미지로 내려받으므로 수 분 걸린다. 데이터만 빠르게 다시 만들려면
`--skip-thumbnails`를 붙인다.

**썸네일을 왜 내려받는가**: GEE가 주는 URL은 만료된다. 링크만 저장하면 며칠 뒤 깨진다.
반대로 고해상도 실사영상(Esri Wayback)은 자격증명 없는 공개 타일이라 URL을 그대로 둔다.

산출물은 커밋한다. Vercel이 git에서 빌드하므로 저장소에 있어야 배포본에 들어간다.
필지 데이터나 점수가 바뀌면 이 스크립트를 다시 돌리고 커밋해야 배포본에 반영된다.

## 2. Vercel (UI)

프로젝트 설정에서 **Root Directory를 `ui`로** 지정한다. 저장소 루트가 Python 프로젝트라
그대로 두면 Next.js를 찾지 못한다.

환경변수:

| 변수 | 값 | 없으면 |
|---|---|---|
| `NEXT_PUBLIC_STATIC_API` | `1` | 조회가 localhost:8001을 부르다 실패 |
| `NEXT_PUBLIC_API_BASE` | 최소 백엔드 URL | AGENT·보고서·점검등록이 "서버 미연결"로 표시(나머지는 정상) |

`NEXT_PUBLIC_API_BASE`를 비워도 화면 대부분은 동작한다. 백엔드를 나중에 붙일 수 있다.

로컬에서 배포본과 같은 모드로 확인하려면 `ui/.env.local`에 같은 값을 넣고 dev 서버를
재시작한다(`.env*`는 gitignore 대상이라 커밋되지 않는다). 평소 개발에서는 넣지 않는 편이
낫다 — 정적 모드에서는 백엔드 데이터를 고쳐도 스냅샷을 다시 굽기 전에는 화면에 반영되지
않아 혼란스럽다.

## 3. 최소 백엔드

`api_min.py` — geopandas·pyproj·shapely·matplotlib·earthengine-api가 필요 없다.
GEE 자격증명도 배포 환경에 둘 필요가 없다(썸네일은 이미 구워져 있다).

로컬 실행:

```bash
pip install -r requirements-min.txt
ALLOWED_ORIGINS=https://<배포도메인> python -m uvicorn api_min:app --port 8001
```

Render 배포는 저장소의 `render.yaml`(Blueprint)에 정의돼 있다. 수동으로 만들 때 틀리기
쉬운 두 곳을 파일로 고정해 뒀다 — 빌드에 `requirements.txt`가 아니라
`requirements-min.txt`를 쓰는 것, 시작 명령이 `--host 0.0.0.0 --port $PORT`로
바인딩하는 것. 둘 중 하나만 틀려도 배포가 붙지 않는다.

환경변수:

| 변수 | 용도 |
|---|---|
| `GEMINI_API_KEY` | AGENT·주간의견 |
| `ALLOWED_ORIGINS` | Vercel 도메인 (쉼표 구분). **없으면 CORS에 막힌다** |
| `STATIC_API_DIR` | 스냅샷 경로(기본 `ui/public/api`) |

`GEE_*`, `VWORLD_API_KEY`는 최소 백엔드에 필요 없다.

**호스트 선택**: 상시 실행 컨테이너(Render·Railway·Fly)여야 한다. 서버리스는 Gemini
30~40초 응답이 함수 제한시간에 걸린다.

**무료 티어로 충분하다.** 비활성 시 잠들어 첫 요청이 40~60초 걸리지만, 화면이 경과 시간에
따라 무엇을 기다리는지 알려 준다(`lib/useWaitingNotice.ts`). 조회 화면은 정적 파일이라
백엔드가 자고 있어도 지도·목록·근거·검증이 즉시 뜨고, 느려지는 건 AGENT·보고서·점검등록
셋뿐이다. 심사위원이 링크를 여는 순간 백지를 보는 상황은 애초에 생기지 않는다.

문구는 단계별로 바뀐다 — AGENT는 정상일 때도 30~40초 걸리므로 그 구간을 고장처럼 보이게
하지 않고(무엇을 하는 중인지 설명), 45초를 넘겨서야 절전 해제 가능성을 언급한다. 반대로
점검 등록은 원래 즉시 끝나므로 4초만 넘어도 안내가 뜬다.

## 알아둘 한계

- **점검 등록은 프로세스 재시작 시 사라진다.** `module_o/store.py`가 인메모리이고 디스크
  저장이 없다. 프로토타입 시연 범위에서는 의도된 동작이며, 실제 도입 시 이 자리에 기관
  DB가 들어간다. 시연 직전에 등록해 둔 결과는 재배포하면 없어진다는 뜻이기도 하다.
- **스냅샷은 굽은 시점의 고정된 값이다.** 위성 관측이 갱신돼도 다시 굽지 않으면 그대로다.
- `.env`는 커밋하지 않는다. 키는 각 호스트의 환경변수로 넣는다.
