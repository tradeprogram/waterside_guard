## 1. 프로젝트 한 줄 요약
KECI(한국환경보전원) 수변녹지 현장점검 우선순위를 위성 변화탐지 + GIS 위험도 점수로 자동 산출하는 의사결정지원 시스템. 2026 대국민 환경혁신 아이디어 공모전(마감 9/30) 제출용 프로토타입.

## 2. 이미 끝난 것 (다시 결정할 필요 없음)
- **아키텍처 확정**: `ARCHITECTURE.md` §1~§13 — 모듈 구성(OBS/CHG/AGG/RISK/O/FIELD/VERIFY/AGENT), envelope 규약(`status/fallback_tier/data/warnings`), 좌표계(내부 EPSG:5179, 출력 EPSG:4326), 7단계 상태머신, 기술스택(FastAPI+GeoPandas+Next.js+MapLibre+PostGIS)

- **실증 AOI 데이터 확보 완료**: 아래 3번 참조
- **API 키**: V-World, Sentinel Hub/Copernicus 둘 다 사용자가 이미 보유 — 리포의 `.env`/secrets에 넣고 시작하면 됨. 절대 코드에 하드코딩하지 말 것.

## 4. 첫 번째 마일스톤 — Data MVP (로드맵 9/1–9/5 구간)
목표: 위 CSV의 PNU 코드로 **필지 폴리곤(geometry)을 복원**해서, 위성 변화탐지를 얹을 수 있는 AOI(관심지역) 레이어를 만든다.

**방법**: 브이월드(V-World) WFS 데이터 API, 연속지적도 서비스(서비스ID `LP_PA_CBND_BUBUN`)를 PNU로 필터링해서 조회.

**추천 경로 (raw WFS 직접 호출보다 이걸 먼저 시도할 것)**: 오픈소스 파이썬 라이브러리 [`PublicDataReader`](https://github.com/WooilJeong/PublicDataReader) (`pip install PublicDataReader`)가 이 조회를 이미 감싸고 있음:
```python
from PublicDataReader import VworldData
api = VworldData(SERVICE_KEY)
geo = api.get_data("연속지적도", attrFilter="pnu:like:4146110500100780003")
# GeoJSON dict 반환
```
raw WFS 엔드포인트/CQL_FILTER 문법을 직접 조사하는 대신 이 라이브러리로 85건(유방동)부터 조인 테스트 → 성공하면 6,275건 전체로 확장.

**완료 기준**: 유방동 85필지의 polygon GeoJSON을 확보하고, QGIS나 간단한 스크립트로 시각화해 실제 위치(용인시 처인구)와 대략 일치하는지 눈으로 검증.

**막히면**: V-World 개발자 문서(`vworld.kr/dev`)는 봇 접근을 막아두고 있어 자동 크롤링이 안 됨 — 사용자가 브라우저로 직접 로그인해서 API 레퍼런스를 확인하거나, PublicDataReader 라이브러리의 소스코드(`VworldData` 클래스)를 직접 읽는 게 더 빠름.

## 5. 그다음 순서 (로드맵 참고, `ARCHITECTURE.md` §11 Backtest 계획과 연동)
