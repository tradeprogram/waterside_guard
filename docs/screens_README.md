# 제안서 시각자료

2026년 대국민 환경혁신 아이디어 공모전 — 「수변생태벨트 점검 우선순위 지원시스템」

배포본: https://waterside-guard.vercel.app
저장소: https://github.com/tradeprogram/waterside_guard

**모든 숫자는 실제 산출물에서 나왔다.** 추정치로 채운 효과 그래프나 라벨 없이 그린
정확도 수치는 여기에 없다 — 제안서에 들어가는 값은 전부 재현 가능해야 한다.

## 1_도식_차트 (matplotlib, 200 DPI)

`python scripts/generate_figures.py`로 재생성 가능하다(실행 중인 API 필요).

| 파일 | 내용 | 제안서에서의 역할 |
|---|---|---|
| **F1_ablation_seasonal_falsepositive** | 계절 오탐 **6건 → 0건**. 두 기간 차분 1·2·3·4·6·7위가 22~54위로 밀려난 표 | **가장 중요.** 현장 라벨 없이 낼 수 있는 유일한 정량 근거 |
| **F5_seasonal_baseline_principle** | 과거 3년 같은 계절 정상범위 띠 + 올해 값이 그 밖에 찍힌 그림 | "작년 6월과 올해 4월을 비교하면 당연한 것 아닌가"에 대한 답 |
| **F3_workflow** | 위성이 후보를 좁히고 사람·드론이 확정하는 흐름 | "드론을 대체하지 않는다" — 범위 설정 |
| **F_route_savings** | Top10 146→122km(−16%), Top20 415→252km(−39%) | 운영 효율. 직선거리 기준임을 그림에 명시 |
| **F11_score_breakdown** | 요인별 기여도 + **결측 2요인을 빗금으로 표기** | 불확실성을 숨기지 않는다는 태도 |
| **F10_site_distribution** | 한강수계 6개 시/군/구 60필지 분포 + 등급 구성 | 실증 범위 |
| **F9_architecture** | 8모듈 구조와 폴백 계층 | 구현 실재성 |

## 아직 만들 수 없는 그림

- **커버리지 곡선**, **Precision@K** — 현장점검 라벨(정답지)이 없어 산출 불가.
  검증 엔진은 구현돼 있고 라벨만 들어오면 즉시 나온다.

**라벨 없이 이 수치를 채워 넣지 않는다.** 0.5m급 영상으로도 수변녹지의 훼손 유형
(예초 vs 식생 소실)은 판별되지 않아, 현장 또는 드론 확인을 거쳐야 정답지가 만들어진다.
그 자리를 대신하는 것이 F1(계절 기준선 적용 효과)이다.
